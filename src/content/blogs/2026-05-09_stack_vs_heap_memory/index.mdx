# You need to understand `Memory`

Ok, so when you create a variable `x=5`, what do you think happens here? did even know where the variable is stored?

well guess what, its stored in your **RAM (Random Access Memory)**.

<img src={ramSvg.src} width="400" height="400" alt="RAM structure" />

This is the component that stores all of your programs variables, such as your google chrome default theme or your even vector position in fortnite.

<img src={fortniteSvg.src} width="500" height="500" alt="RAM structure" />

Every single variables you define or initialize in your program is all stored in the RAM. Even if you are reading from a file, its usually buffered in memory. Hence why RAM is an essential component for any computer.

However there is a huge downside using memory, **Memory are `volatile`**. It means if your program or computer crash, all of your data in memory are gone. Disappear from your life. Basically unrecoverable. This is why we store persistent data in the disk (SSD, HDD, NVMe are your typical disk in your computer).

# Types of Memory

Now memory is divided into two sections, the `stack` and `heap` memory. These types of memory differs in terms on a how a variable is allocated and how it handles the lifecycle of each variable. A `lifecycle` is basically how long a variable is going to live in the program. We will go in detail on each of these memory section below

## Stack is literally a stack

**A stack is region in memory where local variables, function parameters, and return address are stored**. A stack works as a LIFO (last-in, first-out) data structure to handle allocation and de-allocation of its variables or function call.
